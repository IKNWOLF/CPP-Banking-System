# 🏦 C++ OOP Banking System

A simple and functional **Banking System** built using **Object-Oriented Programming (OOP)** in C++.  
It includes client management, user management, and basic banking operations with file storage.

---

## 🚀 Features

### 👤 Client Management
- Add clients  
- Update clients  
- Delete clients  
- Search for clients  
- View all clients  

### 👥 User Management
- Add system users  
- Manage permissions  
- Login authentication  

### 💰 Banking Operations
- Deposit  
- Withdraw  
- Transfer  
- Check balance  
- Transaction logging  

---

## 🛠 Technologies Used
- C++  
- OOP (Classes, Encapsulation, Inheritance)  
- File handling  
- Visual Studio  

---
## 🧩 OOP Concepts Used
- Classes & Objects  
- Encapsulation  
- Abstraction  
- Inheritance (Admin/User roles)  
- File persistence
